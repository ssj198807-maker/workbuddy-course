## 附录 C · 讲师必备清单

> 每次上课前讲师自检。

### C.1 课前 24 小时
- [ ] 自己跑一遍当节课的成果物
- [ ] 截图存档（至少 3 张关键步骤）
- [ ] 整理"故障卡"（最常见 3 个报错 + 解法）
- [ ] 把"任务说明"模板发给学员
- [ ] 清点教具（演示用素材 / Skill / 连接器）

### C.2 课前 1 小时
- [ ] 测试 WorkBuddy 登录状态
- [ ] 测试连接器连通性
- [ ] 测试 Skill 可用性
- [ ] 准备好录屏工具
- [ ] 准备好互动问题

### C.3 课堂 90 分钟节奏
```
0-10    课前回顾 + 本节目标
10-30   核心概念讲解（why + what）
30-60   现场演示（how）
60-80   学员实操（do）
80-90   总结 + 课后作业
```

### C.4 课后 24 小时
- [ ] 收作业 + 给反馈
- [ ] 更新"故障卡"（本节出现的新问题）
- [ ] 给学员推送下一节预习材料
- [ ] 整理本节录屏 + 笔记
- [ ] 更新学员进度表

## 附录 D · 学员常见问题 FAQ

### Q1：我是真的零基础，能学会吗？
A：能。**第一篇 10 章就是为零基础设计**的。按顺序学，每天 1 小时，10 天入门。

### Q2：我数学/代码不好，能用 WorkBuddy 吗？
A：能。WorkBuddy 的核心是"任务说明"——用自然语言写清楚你要什么，**不需要任何代码**。

### Q3：装上 Skill 就能跑通吗？
A：不能。**Skill 只是能力，需要你设计任务 + 验收**。参考第 4/5 章。

### Q4：AI 给的答案我直接能用吗？
A：不能。**所有 AI 输出都必须人工验收**——特别是涉及外发（邮件/发布/合同/删文件）的任务。

### Q5：自动化任务能完全无人值守吗？
A：不能。**所有自动化任务必须配监控告警**——出问题要立刻知道。参考第 10/25 章。

### Q6：多 Agent 一定比单 Agent 好？
A：不一定。**任务简单就别上多 Agent**——单 Agent 跑通再加。多 Agent 是因为"单 Agent 跑不动"才用。

### Q7：我能不能把 Skill 卖给别人？
A：能，但要符合 WorkBuddy 平台规定 + 你蒸馏的源材料版权允许。

### Q8：课程学完我能达到什么水平？
A：参考 `00_课纲总览.md` 的"认证等级"——初级/中级/高级，对应 3 档不同能力。

### Q9：学完这个课程还要学什么？
A：
- 想做内容 → 自学爆款拆解 + 自媒体运营
- 想做技术 → 学 Python + LangChain / LangGraph
- 想做商业 → 学第一性原理 + 客户访谈
- **AI 不会替代你，但会用 AI 的人会**

### Q10：找不到合适 Skill 怎么办？
A：3 步走：
1. 在 WorkBuddy 市场搜（看评价数 + 更新时间）
2. 找社区贡献者定制
3. 自己蒸馏（参考第 22 章）
