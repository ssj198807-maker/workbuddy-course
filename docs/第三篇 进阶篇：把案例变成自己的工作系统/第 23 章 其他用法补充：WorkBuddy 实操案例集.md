## 第 23 章 · 其他用法补充：WorkBuddy 实操案例集

| 项 | 内容 |
|---|---|
| **课时** | 60 min |
| **难度** | ★★ |
| **核心目标** | 拓宽"AI 能做什么"的认知 |
| **学习成果** | 复刻 3-5 个补充案例 |

### 章节内容

#### 23.1 案例 1：简历生成（5 min）
- 输入：3 段经历 + 目标岗位
- 输出：3 个版本的简历（保守 / 标准 / 突破）
- 关键：**只用已有事实，不虚构经历**

#### 23.2 案例 2：会议录音 → 待办（10 min）
- 输入：30 min 会议录音
- 输出：纪要 + 5-10 条待办
- 关键：人名/数字必须二次确认

#### 23.3 案例 3：微信公众号排版发布（10 min）
- 输入：Markdown 原文
- 输出：HTML 排版 + 公众号草稿
- 关键：**绝不直接点"发布"**——必须人工

#### 23.4 案例 4：Excel 119 份门店数据清洗（10 min）
- 输入：119 份格式不一的 Excel
- 输出：1 份标准化数据 + 1 个交互看板
- 关键：先有清洗规则，不擅自补全

#### 23.5 案例 5：年报深度研究（10 min）
- 输入：1 家公司 10 年年报
- 输出：关键指标 10 年趋势 + 横向对比
- 关键：所有数字可追溯

#### 23.6 案例 6：GSAP 粒子动画网站（5 min）
- 输入：设计师的一句话需求
- 输出：完整 HTML + CSS + JS
- 关键：参考图必给、AI 简化 ≠ 客户原意

#### 23.7 案例 7：AI 资讯日报（5 min）
- 输入：5 个资讯源
- 输出：早 9 点飞书推送
- 关键：少而准（参第 15 章）

#### 23.8 案例选择决策表（5 min）
- 「想提升工作效率」→ 案例 1/2/3
- 「想学习商业 / 投资」→ 案例 5
- 「想做内容 / 自媒体」→ 案例 7
- 「想做数据 / 看板」→ 案例 4
- 「想做创意 / 设计」→ 案例 6

### 教学要点
- ✅ **每个案例都要给"踩坑清单"**
- ❌ 不要演示"花活"——重点是普适性

### 课后作业
- 复刻 1 个补充案例
- 输出：1 份你自己的"案例包"（任务说明 + 验收标准 + 踩坑清单）
