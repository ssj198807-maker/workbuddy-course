## 1. 会议的真相（10 min）

### 1.1 三个数据（讲师板书）

- **70% 的会议没有明确纪要**
- **50% 的待办在会后 1 周被遗忘**
- **30% 的会议可以邮件替代**

讲师话术：

> "**AI 团队的真正价值不是做会议纪要——是让会议的'待办'活下去。**"

### 1.2 会议失败的 3 个根因

| 根因 | 表现 | 后果 |
|---|---|---|
| **没纪要** | 散会后谁负责什么不清楚 | 扯皮 |
| **没分人** | 待办没具体负责人 | 没人做 |
| **没跟踪** | 待办分完就忘 | 1 周后归零 |

---

## 2. 会议全流程 AI 化（15 min）

### 2.1 三阶段

```
会前  →  会中  →  会后
排议程   实时纪要   待办分发 + 进度跟踪
```

### 2.2 各阶段的 AI 任务

| 阶段 | AI 任务 | 关键技巧 |
|---|---|---|
| **会前** | 拉历史邮件/文档，生成议程 | **议程必须人工确认** |
| **会中** | 实时转录 + 关键决策标注 | **关键决策必须复读一次** |
| **会后** | 整理纪要 + 拆解待办 + 分配 | **待办必须有时间 + 负责人** |

### 2.3 黄金 24 小时

讲师话术：

> "**会后 24 小时内必须分发明**——错过这个窗口，待办就死了。
> **AI 团队的价值就是：保证 24 小时内不漏分发。**"

---

## 3. 团队设计（15 min）

### 3.1 4 Agent 团队

| Agent | 职责 | 关键约束 |
|---|---|---|
| **会前 Agent** | 拉资料 + 生成议程 | 议程必有人工 |
| **会中 Agent** | 实时转录 | **不上传云端** |
| **会后 Agent** | 纪要 + 待办 + 飞书任务 | 待办必有人工确认 |
| **跟踪 Agent** | 每周检查待办进度 | 进度异常要告警 |

### 3.2 任务流

```
会前 1 天：会前 Agent 拉资料 + 生成议程
                ↓ 人工确认
会前 30 min：议程同步到参会人
                ↓
会中：会中 Agent 实时转录
                ↓
会后 30 min：会后 Agent 出纪要
                ↓ 人工确认
会后 24 h：会后 Agent 分发待办（飞书任务）
                ↓
每周一：跟踪 Agent 检查进度
                ↓ 异常告警
```

### 3.3 关键设计

| 设计点 | 做法 |
|---|---|
| **议程确认** | 会前 1 天发给参会人，无修改 → 锁定 |
| **转录** | 本地化，不上传第三方 |
| **关键决策** | 会上必须复读一遍（防 AI 听错） |
| **待办分配** | 必有人工 @（AI 不能直接 @ 别人） |
| **进度跟踪** | 每周一自动汇总，异常推飞书 |

## 4. 现场演示（10 min）

### 4.1 演示准备
- 1 段 30 分钟的真实会议录音（学员自己公司 or 训练用）
- 4 Agent 已配置
- 飞书任务已连接

### 4.2 演示步骤

1. 播放 5 分钟录音片段（**先放给学员听**）
2. 演示"会中 Agent"实时转录
3. 演示"会后 Agent"出纪要 + 待办
4. 演示"会后 Agent"分发到飞书
5. 演示失败模式：人名转写错 / 待办没负责人

### 4.3 演示话术

讲师话术：

> "**注意看人名——AI 经常把'张总'写成'张聪'。**
> **所有关键人名/数字必须二次确认。**
> 这是为什么'会后 Agent'只出待办框架，**分配必须人工**。"

---

## 5. 安全红线（10 min）★ 重点

### 5.1 强红线（**必须念给学员**）

1. **会议录音必须本地化**——不能上传到第三方
2. **纪要中的人名/金额必须二次确认**——AI 转录可能错
3. **待办分配必须人工**——AI 不能直接 @ 别人
4. **敏感会议不录音**——比如薪酬、纪律、个人隐私

### 5.2 三类不能录的会议

| 类型 | 原因 |
|---|---|
| **薪酬讨论** | 涉及个人隐私 + 法律风险 |
| **员工纪律** | 涉及个人权益 + 程序合规 |
| **客户未授权** | 涉及商业秘密 + 客户关系 |

### 5.3 学员必学：会议前的"边界声明"

讲师话术：

> "**每场会议开始前，必须声明'本会议会录音用于纪要'**——
> 1. **录前征得同意**——不愿意的就退会或不录
> 2. **录后限定使用**——只用于本次纪要，不外发
> 3. **录后限期删除**——纪要完成后 7 天内删除录音"

---

## 6. 收尾（10 min）

### 课后作业

```
【作业 1：跑 1 个真实会议】
- 用 AI 团队跑全流程
- 1 周后统计"还在跟的待办"比例（应 > 70%）

【作业 2：写边界声明】
- 给你的会议写 1 份"录音边界声明"
- 包含：征得同意、限定使用、限期删除

【作业 3：跟 1 周进度】
- 用跟踪 Agent 跟 1 周
- 统计"完成率"+"逾期率"
- 写出"我的会议效率报告"（1 页）
```

### 关键认知

- ✅ **24 小时是黄金窗口**——错过待办就死
- ✅ **会议失败 3 根因**——没纪要、没分人、没跟踪
- ✅ **强红线 4 条**——本地化、二次确认、人工分配、敏感不录
