## 第 9 章 · 接入外部 API

| 项 | 内容 |
|---|---|
| **课时** | 60 min |
| **难度** | ★★★ |
| **核心目标** | 解决"WorkBuddy 没内置的连接器" |
| **学习成果** | 自己建 1 个 API 连接器 |

### 章节内容

#### 9.1 什么时候需要自建 API（10 min）
- **场景**：你要连的外部系统 WorkBuddy 没提供连接器
- **典型**：自家公司的 CRM、ERP、内部数据库

#### 9.2 API 接入四步法（20 min）
```
1. 找文档   → 2. 申请 Key   → 3. 测接口   → 4. 配连接器
```
- 文档里必看的 5 个字段：
  - 端点（Endpoint）
  - 方法（GET/POST）
  - 鉴权（API Key / OAuth）
  - 请求体（Request Body）
  - 响应体（Response Body）

#### 9.3 三个常见 API 实操（20 min）
- **天气 API**：最简单的 GET 请求
- **飞书机器人 Webhook**：POST + JSON
- **公司 CRM API**：（以学员自己公司为例）实战演练

#### 9.4 故障排查（10 min）
- 401：鉴权失败
- 403：权限不足
- 404：端点错
- 429：调用太频繁
- 500：服务器问题

### 教学要点
- ✅ 让学员**自己公司 API** 做案例，不只是"天气 API"
- ❌ 不要讲 GraphQL / WebSocket 等高级协议

### 课后作业
- 自己公司的 1 个 API → 接入 WorkBuddy
- 跑通 1 个真实任务
