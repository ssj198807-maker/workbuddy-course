## 第 3 章 · 主界面、任务与工作区

| 项 | 内容 |
|---|---|
| **课时** | 45 min |
| **难度** | ★ |
| **核心目标** | 理解"任务"和"工作区"的关系 |
| **学习成果** | 能搭建自己的工作区结构 |

### 章节内容

#### 3.1 主界面四区域（10 min）
- **左栏**：工作区列表（个人/团队/项目）
- **中栏**：任务流（今日 / 本周 / 全部）
- **右栏**：当前任务详情（对话 / 文件 / 进度）
- **顶栏**：全局搜索、新建任务、连接器状态

#### 3.2 任务的三种状态（10 min）
- **进行中**：正在被 AI 执行
- **待验收**：AI 跑完，等你确认
- **已完成**：已确认，归档到工作区
- **关键认知**：待验收 ≠ 已完成，**不验收永远不算交付**

#### 3.3 工作区的搭建（15 min）
- 推荐结构（按角色）：
  - **个人区**：日常任务、灵感记录
  - **项目区**：每个项目一个子工作区
  - **学习区**：课程任务、读书笔记
- **不要做**：把所有任务都丢到「默认工作区」

#### 3.4 任务的元信息（10 min）
- 每个任务应有的字段：
  - 标题（动词开头：「整理」而不是「桌面文件」）
  - 任务说明（边界 + 验收）
  - 关联文件
  - 标签（项目 / 类型 / 优先级）
  - 截止时间

### 教学要点
- ✅ 让每个学员**当场搭建自己的工作区**，不要只是看
- ❌ 不要讲"高级筛选"等花式功能，本章重点是基础认知

### 课后作业
- 搭建自己的 3 个工作区（个人 / 项目 / 学习）
- 在每个工作区里新建 1 个真实任务
