## 第 1 章 · 初识 WorkBuddy

| 项 | 内容 |
|---|---|
| **课时** | 30 min |
| **难度** | ★ |
| **核心目标** | 理解"WorkBuddy 不是聊天工具，是 AI 工作系统" |
| **学习成果** | 能在自己电脑上打开 WorkBuddy 并登录 |
| **关键概念** | 任务（Task）、技能（Skill）、专家（Agent）、专家团（Team） |

### 章节内容

#### 1.1 WorkBuddy 是什么（10 min）
- **是什么**：一个本地 AI 工作台，不是另一个 ChatGPT 网页
- **不是什么**：不是聊天工具、不是单纯的 Agent 平台
- **三个关键词**：
  - **任务（Task）**：今天要交付的成果物
  - **技能（Skill）**：任务需要的具体能力（写文案 / 查天气 / 改 PDF）
  - **专家（Agent）**：调度 Skill 完成任务的"虚拟员工"
  - **专家团（Team）**：多个 Agent 协作完成复杂任务

#### 1.2 为什么需要它（10 min）
- 对比三种 AI 使用方式：
  - **网页聊天**：用完就忘、没沉淀
  - **代码 Agent**：门槛高、非技术人用不了
  - **WorkBuddy**：任务驱动、Skill 可复用、结果可验收
- 一个真实故事：把"我今天要做周报"从"打开 ChatGPT 写两句"升级为"调度三个 Skill 自动生成周报初稿"

#### 1.3 现场演示（10 min）
- 打开 WorkBuddy，演示一个完整任务流程
- 重点不是演示结果，是演示"任务说明"长什么样

### 教学要点
- ✅ 必须让学员**理解"任务说明"是核心**，不是提示词
- ❌ 不要陷入"和 ChatGPT 比哪个强"的讨论

### 课后作业
- 安装 WorkBuddy（参考第 2 章）
- 写下你自己今天要做的 3 个任务（不要写"写文案"，要写"基于本周 5 场客户会议记录生成周报"）
