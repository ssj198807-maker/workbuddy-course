## 第 6 章 · 专家和专家团

| 项 | 内容 |
|---|---|
| **课时** | 60 min |
| **难度** | ★★ |
| **核心目标** | 从"用工具"升级到"调度团队" |
| **学习成果** | 理解"任务 → 团队"的思维跃迁 |

### 章节内容

#### 6.1 专家（Agent）是什么（15 min）
- **类比**：一个能调度多个 Skill 的"虚拟员工"
- **示例**：「秘书小张」Agent = 文档处理 Skill + 日程管理 Skill + 邮件 Skill
- **关键**：Agent 不等于 LLM，Agent 是"调度 LLM + Skill"的协调器

#### 6.2 什么时候用 Agent（10 min）
- **不需要 Agent**：单一任务、单一 Skill 能搞定
- **需要 Agent**：
  - 任务需要 3 个以上 Skill
  - 任务有明确分工（谁先做、谁后做、谁验收）
  - 任务需要持续运行（每天早上自动跑）

#### 6.3 专家团（Team）是什么（20 min）
- **核心概念**：把多个 Agent 组建成一支"AI 团队"
- **三种典型结构**：
  - **流水线型**：Agent A 做 X → Agent B 做 Y → Agent C 验收
  - **协作型**：3 个 Agent 并行处理同一任务的不同部分
  - **层级型**：团长 Agent 调度 3 个兵卒 Agent
- **案例**：「短视频生产团队」= 选题 Agent + 脚本 Agent + 视觉 Agent + 剪辑 Agent

#### 6.4 现场演示（15 min）
- 演示一个三 Agent 协作完成"客户邮件草拟 + 附件整理 + 日程提醒"
- 重点不是演示结果，是演示"如何拆分任务给不同 Agent"

### 教学要点
- ✅ **本章是整个蓝皮书的"分水岭"**——前面是工具，后面是团队
- ❌ 不要讲太复杂的"多 Agent 协议"（第三篇第 24 章才讲）

### 课后作业
- 设计一个属于自己的 3-Agent 团队（写出来，不一定真实现）
- 团队至少要解决你工作中的 1 个真实痛点
