## 第 2 章 · 下载、安装、登录与更新

| 项 | 内容 |
|---|---|
| **课时** | 30 min |
| **难度** | ★ |
| **核心目标** | 全平台安装、登录、保持最新 |
| **学习成果** | 桌面端 + 移动端都能用 |

### 章节内容

#### 2.1 平台选择（5 min）
- **桌面端**：macOS / Windows / Linux（推荐作为主战场）
- **移动端**：iOS / Android（用于临时任务）
- **Web 端**：应急用，不推荐长期使用

#### 2.2 下载与安装（10 min）
- 官方下载地址 + 注意事项
- **国内网络加速方案**（如需要）
- 常见安装失败：
  - macOS「无法打开，因为无法验证开发者」→ 系统设置 → 隐私与安全性 → 仍要打开
  - Windows SmartScreen 拦截 → 更多信息 → 仍要运行

#### 2.3 登录与多端同步（10 min）
- 账号注册（手机号 / 邮箱）
- 首次登录配置（语言、模型选择、连接器授权）
- **多端同步原理**：任务、技能、连接器都同步，但本地文件不自动同步

#### 2.4 更新机制（5 min）
- 自动更新 vs 手动更新
- 大版本更新前的"技能兼容性"检查

### 教学要点
- ✅ 现场帮助学员**解决安装报错**，不要只演示成功路径
- ❌ 不要讲"如何破解"或"如何换源"等灰色话题

### 课后作业
- 完成桌面端 + 移动端登录
- 截图保存，作为"环境就绪"凭证
