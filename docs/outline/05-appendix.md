## 附录 A · 常用指令模板

> 来源：三哥 wiki 内的 `WorkBuddy 43 场景任务说明全指南`（已抓取并整理）
> 这些模板可以直接复制到 WorkBuddy 里使用，只需替换 `【】` 里的个人材料。

### A.1 任务说明 4 要素模板（必背）

```
【任务目标】
我要交付：__________
成功标准：__________

【输入材料】
- 文件 1：__________（路径：__________）
- 文件 2：__________
- 文字描述：__________

【输出格式】
- 文件类型：__________
- 长度：__________
- 结构：__________

【边界条件】
绝对不能做：
- __________
- __________
需要人工确认：
- __________
- __________
```

### A.2 8 个万能任务模板

#### 模板 1：本地文件批量整理
```
【任务】把【文件夹路径】按【分类规则】整理

【分类规则】
- 图片（.jpg/.png/.webp）→ 图片/
- 文档（.docx/.pdf/.md）→ 文档/
- 视频（.mp4/.mov）→ 视频/
- 其他 → _待人工分类/

【边界】
- 不删除任何文件
- 不修改文件内容
- 不移动 .docx / .xlsx（业务文件，单独处理）
- 先出整理计划，确认后再执行
```

#### 模板 2：Excel 数据自动分析
```
【任务】对【Excel 路径】做【分析目标】

【分析目标】
- 描述：__________
- 维度：__________
- 关键问题：__________

【边界】
- 不擅自补全空值
- 数字标"待确认"而不是猜
- 输出公式必须可解释
```

#### 模板 3：周报/月报自动生成
```
【任务】基于【本周工作记录】生成【周/月报】

【内容要求】
- 本周完成：5-8 条
- 数据指标：必须有数字
- 下周计划：3-5 条
- 问题与求助：1-3 条

【边界】
- 不编造未提供的工作成果
- 不夸大数据
- 不写"学习了 XX"这种没交付物的内容
```

#### 模板 4：会议纪要自动生成
```
【任务】基于【会议录音/文字记录】生成纪要

【输出结构】
- 会议基本信息（时间/参与人/主题）
- 关键决策（每条带决策依据）
- 待办清单（负责人 + 截止时间）
- 风险与阻碍
- 下次会议时间

【边界】
- 说不清的内容标"待确认"
- 人名/数字必须二次确认
- 涉及隐私的内容不写入纪要
```

#### 模板 5：多平台文案同步生成
```
【任务】基于【核心内容】生成【平台 1/平台 2/平台 3】三版文案

【核心内容】
- 主题：__________
- 关键信息：__________
- 目标读者：__________

【平台特性】
- 平台 1：__________（字数/风格）
- 平台 2：__________
- 平台 3：__________

【边界】
- 三版事实必须完全一致
- 不虚构数据
- 不夸大承诺
```

#### 模板 6：网页内容抓取整理
```
【任务】抓取【URL】的内容并整理

【抓取范围】
- 需要的内容：__________
- 不需要的内容：__________

【输出格式】
- Markdown / Excel / Word

【边界】
- 抓不到的内容明确告知
- 付费墙内容明确告知
- 不爬登录后的内容
```

#### 模板 7：图片批量处理
```
【任务】对【图片文件夹】做【处理动作】

【处理动作】
- 压缩：目标大小 __________
- 加水印：位置 + 文字
- 改尺寸：目标尺寸 __________

【边界】
- 保留原文件不覆盖
- 先在测试文件夹处理 3 张，确认后再批量
- 失败任务不静默跳过，要报告
```

#### 模板 8：邮件撰写 + 检查
```
【任务】撰写一封【场景】邮件给【收件人】

【场景】
- 收件人：__________
- 我的诉求：__________
- 语气：__________

【检查清单】
- 主题明确
- 称谓正确
- 关键信息无错别字
- CTA 明确
- 附件正确

【边界】
- 未经确认绝不自动发送
- 涉及金额/合同/承诺必须人工
```

## 附录 D · 学员常见问题 FAQ

### Q1：我是真的零基础，能学会吗？
A：能。**第一篇 10 章就是为零基础设计**的。按顺序学，每天 1 小时，10 天入门。

### Q2：我数学/代码不好，能用 WorkBuddy 吗？
A：能。WorkBuddy 的核心是"任务说明"——用自然语言写清楚你要什么，**不需要任何代码**。

### Q3：装上 Skill 就能跑通吗？
A：不能。**Skill 只是能力，需要你设计任务 + 验收**。参考第 4/5 章。

### Q4：AI 给的答案我直接能用吗？
A：不能。**所有 AI 输出都必须人工验收**——特别是涉及外发（邮件/发布/合同/删文件）的任务。

### Q5：自动化任务能完全无人值守吗？
A：不能。**所有自动化任务必须配监控告警**——出问题要立刻知道。参考第 10/25 章。

### Q6：多 Agent 一定比单 Agent 好？
A：不一定。**任务简单就别上多 Agent**——单 Agent 跑通再加。多 Agent 是因为"单 Agent 跑不动"才用。

### Q7：我能不能把 Skill 卖给别人？
A：能，但要符合 WorkBuddy 平台规定 + 你蒸馏的源材料版权允许。

### Q8：课程学完我能达到什么水平？
A：参考 `00_课纲总览.md` 的"认证等级"——初级/中级/高级，对应 3 档不同能力。

### Q9：学完这个课程还要学什么？
A：
- 想做内容 → 自学爆款拆解 + 自媒体运营
- 想做技术 → 学 Python + LangChain / LangGraph
- 想做商业 → 学第一性原理 + 客户访谈
- **AI 不会替代你，但会用 AI 的人会**

### Q10：找不到合适 Skill 怎么办？
A：3 步走：
1. 在 WorkBuddy 市场搜（看评价数 + 更新时间）
2. 找社区贡献者定制
3. 自己蒸馏（参考第 22 章）
