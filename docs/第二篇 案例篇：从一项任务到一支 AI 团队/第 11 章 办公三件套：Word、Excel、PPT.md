## 第 11 章 · 办公三件套：Word、Excel、PPT

| 项 | 内容 |
|---|---|
| **课时** | 90 min |
| **难度** | ★★ |
| **核心目标** | 用 AI 团队替代 70% 日常办公任务 |
| **学习成果** | 3 份成品文件 + 1 套可复用模板 |

### 章节内容

#### 11.1 团队设计（15 min）
- **Word 专家团** = 文档整理 Agent + 模板格式化 Agent + 校对 Agent
- **Excel 专家团** = 数据清洗 Agent + 公式生成 Agent + 图表生成 Agent
- **PPT 专家团** = 大纲生成 Agent + 内容扩展 Agent + 视觉设计 Agent

#### 11.2 Word 任务实战（20 min）
- 任务示例：「把 5 份客户合同扫描件整理成统一格式的 Word 文档」
- 关键技巧：
  - **绝对不要让 AI 改合同条款**——只做格式整理
  - 验收标准：双栏对齐、字号统一、签字位保留

#### 11.3 Excel 任务实战（25 min）
- 任务示例：「清洗 119 份门店销售数据，生成可交互运营看板」
- 关键技巧（**蓝皮书核心场景**）：
  - **数据清洗要先有"清洗规则"**，不要让 AI 自己决定
  - **不擅自补全无法确认的数据**——标"待确认"而不是猜
  - **公式必须解释用途**——学员要看得懂
- 延伸参考：三哥 wiki 内《门店 Excel 看板》案例

#### 11.4 PPT 任务实战（25 min）
- 任务示例：「基于本月工作日志，生成一份 12 页的月度汇报 PPT」
- 关键技巧：
  - **每页只保留一个核心观点**——不为凑页数拆段
  - **图表由 AI 生成，但配文由你写**——避免"AI 腔"
  - **设计风格必须有参考图**——别让 AI 自由发挥

#### 11.5 三件套的协作（5 min）
- 「客户分析报告」= Excel 数据 + Word 解读 + PPT 展示
- 一个团队调度，三个产品

### 教学要点
- ✅ **每个文件都要有"参考样板"**——AI 没有参考就一定做错
- ❌ 不要演示"完全让 AI 自由发挥"

### 课后作业
- 用 AI 团队完成 1 份 Word + 1 份 Excel + 1 份 PPT
- 三份必须服务于同一个真实业务场景
