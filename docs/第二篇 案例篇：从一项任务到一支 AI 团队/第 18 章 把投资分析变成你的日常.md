## 第 18 章 · 把投资分析变成你的日常

| 项 | 内容 |
|---|---|
| **课时** | 60 min |
| **难度** | ★★★ |
| **核心目标** | 让 AI 团队替你"读财报" |
| **学习成果** | 1 套"个人投资看板" |

### 章节内容

#### 18.1 个人投资分析的现实（10 min）
- 三个常见误区：
  - 每天看行情 → 频繁交易 → 亏损
  - 听消息面 → 追涨杀跌 → 后悔
  - 不会读财报 → 错过好公司 / 踩雷差公司
- AI 团队的定位：**替你做"读 + 整理"，决策你做**

#### 18.2 投资分析的 4 步法（15 min）
```
1. 选标的    → 2. 读财报    → 3. 横向对比    → 4. 决策记录
```

| 步 | AI 任务 | 边界 |
|---|---|---|
| 选标的 | 监控公告 + 行业新闻 | 不推荐买卖 |
| 读财报 | 抓年报 + 关键指标提取 | 不预测股价 |
| 横向对比 | 同行业 5 家公司对比表 | 不写"应该买" |
| 决策记录 | 买入卖出 + 理由 | 不自动下单 |

#### 18.3 团队设计（15 min）
- **监控 Agent**：公告 + 研报 + 新闻
- **财报 Agent**：年报抓取 + 关键指标提取（参考三哥 wiki《上市公司深度研究方法》案例）
- **对比 Agent**：同行业 5 家公司横向对比
- **复盘 Agent**：每季度决策复盘

#### 18.4 现场演示（10 min）
- 跑通"读一份年报 → 提取 5 个关键指标 → 写一句话总结"
- 演示失败模式：年报里数据错误、AI 提取字段错位

#### 18.5 强红线（5 min）
- **绝对不能自动下单**——所有买卖必须人工
- **绝对不能给"建议买/卖"判断**——只给事实
- **所有数据来源必须可追溯**——AI 不能编年报数字

### 教学要点
- ✅ 强调**"AI 给事实，决策你做"**
- ❌ 不要演示"AI 选股"——蓝皮书反模式

### 课后作业
- 用 AI 团队分析 1 家公司（不一定是自己持仓的）
- 写出"事实清单"+"我自己的判断"（分清楚）
