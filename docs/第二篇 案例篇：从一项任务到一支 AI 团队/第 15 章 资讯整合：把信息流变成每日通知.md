## 第 15 章 · 资讯整合：把信息流变成每日通知

| 项 | 内容 |
|---|---|
| **课时** | 60 min |
| **难度** | ★★★ |
| **核心目标** | 让 AI 替你"读"信息 |
| **学习成果** | 1 套"每日推送"工作流 |

### 章节内容

#### 15.1 信息流的三种处理（10 min）
- **被动接收**：每天刷 30 min 但记不住
- **手动整理**：用工具收藏但不再看
- **AI 推送**：每天 9 点把"我关心的 5 件事"送到眼前

#### 15.2 资讯整合 4 步法（20 min）
```
1. 源筛选   → 2. 内容抓取   → 3. AI 摘要   → 4. 推送通知
```

| 步 | 工具 | 失败模式 |
|---|---|---|
| 源筛选 | RSS / API / 爬虫 | 选了太多 → 噪音 |
| 内容抓取 | 网页抓取 Skill | 反爬 / 付费墙 |
| AI 摘要 | LLM | 摘要变"读后感" |
| 推送通知 | 飞书 / 邮件 / 公众号 | 推送时间不对 |

#### 15.3 团队设计（15 min）
- **采集 Agent**：5 个 RSS 源
- **过滤 Agent**：关键词 + 重复检测
- **摘要 Agent**：每条 200 字内 + 3 条关键判断
- **推送 Agent**：早 9 点准时推飞书

#### 15.4 现场演示（10 min）
- 配一个"AI 行业每日 5 条"推送
- 演示失败模式：源失效、摘要过长、推送时间错

#### 15.5 进阶：和知识库联动（5 min）
- 推送的每条资讯可以**自动归入"待读"知识库**
- 读完/打标签后自动归类（参考第 16 章）

### 教学要点
- ✅ 强调**"少而准"**——5 条好资讯 > 50 条噪音
- ❌ 不要演示"全网爬取"——容易被封号

### 课后作业
- 配 1 套每日资讯推送（最多 5 个源）
- 跑 7 天，统计"真正读完"的比例（应 > 60%）
