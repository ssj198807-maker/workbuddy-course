## 第 14 章 · 生活助手的价值

| 项 | 内容 |
|---|---|
| **课时** | 30 min |
| **难度** | ★ |
| **核心目标** | 让 AI 帮你处理琐碎 |
| **学习成果** | 5 个生活场景小工具 |

### 章节内容

#### 14.1 为什么把生活场景放在第二篇（5 min）
- 生活场景难度低，**特别适合做"练手项目"**
- 把工作中已经会的套路迁移到生活

#### 14.2 5 个经典场景（20 min）

| 场景 | AI 团队 | 边界 |
|---|---|---|
| **每日天气 + 穿衣建议** | 天气 API + LLM 改写 | 不发朋友圈，只给自己 |
| **每周菜谱** | 冰箱照片 + 营养 API + 菜谱生成 | 过敏原必标 |
| **家庭账本** | 微信账单 + 分类 Agent | 不连银行 App |
| **纪念日提醒** | 日历 + LLM 写祝福语 | 不自动发红包 |
| **旅行规划** | 高德/小红书 API + 行程生成 | 不订机票/酒店 |

#### 14.3 生活 vs 工作的关键差异（5 min）
- 工作中：**任务驱动**
- 生活中：**场景驱动**（没有 deadline，AI 容易做"过设计"）
- 解决：每个生活场景**必须设"完成标志"**，没设就停不下来

### 教学要点
- ✅ 让学员**从生活场景起步，建立"完成感"**
- ❌ 不要演示"全自动管家"——那是科幻

### 课后作业
- 选 3 个生活场景，跑通至少 1 个
- 给每个场景写"完成标志"
